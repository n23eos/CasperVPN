# test/chaos — устойчивость и chaos-тесты (плейсхолдер)

Владелец: reliability. Пока пусто — заложено на волне фундамента.

Назначение: проверять антихрупкость, а не только отказоустойчивость:

- Отказ/блок одного `TransportType` → система переключается (не монокультура).
- Блок ноды из региона → автозамена оркестратором, бесшовный переезд юзеров.
- Блок основного домена подписки → доставка через запасной `DeliveryChannel`.
- Потеря per-user изоляции не каскадит на других юзеров.

Гоняет сценарии поверх `docker-compose.dev.yml` и контрактных API. Бизнес-логику
не дублирует — дёргает сервисы через их OpenAPI-интерфейсы.
