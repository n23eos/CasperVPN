# web/admin — панель оператора (плейсхолдер)

Владелец: команда admin UI. Пока пусто — заложено на волне фундамента.

Назначение: операторская панель поверх API сервисов (мониторинг флота нод,
управление юзерами/подписками, карта блокировок из телеметрии).

Границы: потребляет **только** публичные/внутренние API из
`packages/contracts/openapi/*.yaml`. Свои типы данных не изобретает — берёт из
замороженного контракта. См. корневой `CLAUDE.md` (карта владения, заморозка).
