# Приватная панель оператора

Панель запускается локальным read-only сервером. Браузер получает только
безопасную проекцию данных, а токены control-plane и billing остаются в
серверном процессе.

```sh
python3 scripts/operator.py --env .launch/production.env
```

Откройте `http://127.0.0.1:8090`. Сервер принимает только loopback bind,
проверяет `Host` и `Origin`, не предоставляет изменяющих маршрутов и не
пересылает браузеру исходные ответы сервисов.

Для локальной проверки интерфейса без сервисов:

```sh
python3 scripts/operator.py --demo-fixtures --port 8090
```

В этом режиме наверху всегда показана метка демонстрационных данных. Полные
настройки, systemd units, мониторинг и backup описаны в `docs/OPERATIONS.md`.
