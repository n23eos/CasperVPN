# План: фундамент монорепо CasperVPN + заморозка контрактов

Источник истины — `architecture.md`. Цель волны: компилящийся скелет + **замороженные**
межсервисные контракты, чтобы 6 агентов строили подсистемы параллельно без конфликтов.

## Критерий успеха (verify)
1. `make build` — все Go-модули компилируются (сервисы = заглушки-`main`, проходящие сборку).
2. `make lint` — golangci-lint проходит на скелете.
3. `go vet ./...` в каждом модуле чист.
4. `packages/contracts/` заморожен: типы Go + JSON Schema + OpenAPI согласованы.
5. `docs/contracts.md` документирует ВСЕ поля; ADR-001..004 на месте; корневой `CLAUDE.md` с картой владения.

## Структура монорепо
```
CasperVPN/
  go.work                      # Go workspace: contracts + 6 сервисов
  Makefile                     # build test lint up down
  docker-compose.dev.yml       # postgres + 6 сервисов
  .editorconfig  .golangci.yml
  CLAUDE.md                    # карта владения, «contracts заморожены», [АНТИ-БЛОК]
  packages/contracts/          # ЕДИНЫЙ источник типов (module .../contracts)
    *.go                       # Node, Transport(+варианты), User, Subscription, FieldSignal/HealthEvent, enums
    subscription.go            # три представления выдачи (base64 / sing-box JSON / Clash-Meta YAML)
    schema/*.json              # JSON Schema тех же типов
    openapi/                   # control-plane, subscription, delivery, telemetry (OpenAPI 3.1, только сигнатуры)
  services/{control-plane,subscription,delivery,billing,telemetry,orchestrator}/
                               # каждый: go.mod + cmd/<svc>/main.go заглушка
  web/admin/                   # плейсхолдер (README)
  infra/                       # terraform/ansible плейсхолдеры (README)
  test/chaos/                  # плейсхолдер (README)
  docs/{contracts.md, decisions/ADR-00{1..4}.md}
```
Модули: `github.com/caspervpn/<name>`. Сервисы тянут contracts через `go.work` (без внешнего реестра).

## Контракты (заморозить) — с прошитым [АНТИ-БЛОК]
- **Enums:** `NodeStatus, NodeRole, TransportType, TransportVersion, UserStatus, SubscriptionStatus, SubscriptionPlan, SignalType, HealthStatus`.
- **Transport** — тегированный union `Type` + типизированные варианты (указатели): `VlessReality`,
  `AmneziaWG`, `Hysteria2`, `Shadowsocks2022`. Общие поля: `Tag, Port, Enabled, Priority`.
  Домены мимикрии / SNI — **поля**, не хардкод. Нода держит `[]Transport` → несколько типов сразу (не монокультура).
- **Node:** `Role (entry/exit/combined)`, `Status`, `EntryNodeID *` (entry≠exit разделение),
  `RotateAfter` + `EphemeralEntryIP` (быстрая ротация), `Cloud/Region/Provider`, `[]Transport`. Ни одного IP/домена в коде.
- **User:** персональный `RealityShortID` + персональный `UUID`/ключ (блок одного ≠ палит остальных),
  `Status`, `QuotaBytes/UsedBytes`, `DeviceLimit`, `SubscriptionID`.
- **Subscription:** `Plan, Status, StartsAt/ExpiresAt, TrafficLimitBytes, SpeedLimit, Token`.
- **FieldSignal** (петля «где что заблокировали», анонимно, без PII): `NodeID, TransportType/Version,
  Region/ASN/ISP, SignalType (reset/timeout/dpi_block/probe/throttle/dns_poison/handshake_fail/ok),
  RTTms, LossPct, Success, ClientVersion, Platform, Timestamp`.
  **HealthEvent** (пробы оркестратора): `NodeID, Status, ProbeSource, BlockedFromRegions[], Latency, Timestamp`.
- **Subscription-выдача:** один набор нод → три представления, совместимо с Happ и sing-box.

## OpenAPI 3.1 (только сигнатуры)
control-plane (ноды/CRUD), subscription (выдача URL/форматы), delivery (мультиканальная раздача),
telemetry ingest (приём FieldSignal). Пути/запросы/ответы/коды, без реализации.
