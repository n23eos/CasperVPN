# План: сервис orchestrator — замыкание петли антихрупкости

Источник истины — `architecture.md`, `packages/contracts` (заморожены), ТЗ
`docs/wave-2/TZ-orchestrator.md`. Работаем ТОЛЬКО в `services/orchestrator/`
(+ `docs/orchestrator.md`). Внешних зависимостей нет (stdlib + contracts).

## Статус: функционально завершён; проверка тулчейном — на стороне CI/оператора

Контур «блок → замена ноды → юзеры переехали» собран end-to-end на моках. Главный
риск (ротация парка по отравленной телеметрии) закрыт архитектурно: сначала
безопасный мозг (`DRY_RUN=true`, policy-гейт, потолок side-effects), потом руки.

## Критерий успеха (verify)
1. `make build` / `make vet` / `make test -race` зелёные; gofmt чист; покрытие ≥80%.
2. E2e на моках: `authoritative блок + проба → Provisioner.rotate → CP.Node обновлён → старая retired`.
3. Одиночный/некорроборированный `FieldSignal` без подтверждающей пробы **НЕ** ротирует.
4. Интерфейсы `Provisioner`/`Prober`/`ControlPlaneClient`/`TelemetryClient` мокируемы; реальные адаптеры за ними.
5. `docs/orchestrator.md`: контур, контракты стыков, env, что операторское.

## Архитектура (пакеты)
```
services/orchestrator/
  cmd/orchestrator/main.go         # wiring: config → адаптеры → reconcile loop; /healthz; graceful shutdown
  internal/config/config.go        # env; DRY_RUN=true по умолчанию; пороги гейта
  internal/ports/ports.go          # швы: TelemetryClient, ControlPlaneClient, Provisioner, Prober, Clock
  internal/policy/policy.go        # чистый мозг: Recommendations+state+пробы → план; анти-poisoning гейт
  internal/reconcile/reconcile.go  # observe→confirm→plan→act; dry-run по умолчанию; стоп при первой ошибке
  internal/httpx/httpx.go          # bearer, таймауты, конечный retry для идемпотентных запросов
  internal/telemetryclient/        # GET /v1/recommendations, POST /v1/health
  internal/cpclient/               # GET/PATCH /v1/nodes (роль orchestrator)
  internal/provision/script.go     # драйвер node_up/rotate/down.sh: env, timeout, structured result
  internal/probe/probe.go          # MVP TCP-пробер за интерфейсом Prober → HealthEvent
```

## Сделано
- **Каркас + порты + config.** `DRY_RUN=true` дефолт; `Validate` требует URL при `false`.
- **Policy engine (чистый).** `noop/mark_degraded/rotate/replace/retire`; устаревшее
  окно, неизвестная нода, draining/retired — безопасно; потолок `MAX_ACTIONS_PER_CYCLE`.
- **Анти-poisoning гейт.** Необратимое действие только при `authoritative` или
  `corroborated`+свежая подтверждающая проба; иначе максимум `degraded`; вето пробы.
- **HTTP-адаптеры.** telemetry + control-plane за интерфейсами; таймауты, bearer,
  конечный retry (4xx не ретраится, 5xx — ограниченно). httptest 200/401/500/malformed/timeout.
- **Reconcile loop.** observe→confirm(пробы→telemetry)→plan→act; dry-run не трогает инфру.
- **Provisioner.** `ScriptRunner` поверх infra/scripts; env-параметры, timeout, structured error.
- **Автозамена.** replace: node_up ДО draining, retire только после `DRAIN_GRACE` (сосуществование).
- **Плановая ротация + Prober.** `rotate_after`; MVP TCP-пробер, вердикт → `POST /v1/health`.
- **Тесты.** policy — ядро безопасности исчерпывающе; reconcile — e2e на моках
  (порядок, rollback, потолок, устойчивость к outage telemetry); адаптеры/скрипты/пробер.

## НЕ сделано / осталось
1. **Go-тулчейн недоступен в dev-контейнере** (офлайн). Код сверен вручную с
   замороженными контрактами; `make build/vet/test -race` и gofmt — прогнать в CI.
2. **Реальные пробы из РФ** — операторские vantage-точки; `TCPProber` это MVP.
3. **Реальный apply инфры и облачные креды** — оператор (`OPERATOR-CHECKLIST.md`).
