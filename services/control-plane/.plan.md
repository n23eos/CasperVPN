# План: control-plane (мозг CasperVPN)

Источник истины — `../../architecture.md` + замороженные `packages/contracts`.
Работаем ТОЛЬКО в `services/control-plane/`. Go + Postgres, чистая архитектура.

## Критерии приёмки (verify)
1. `make build` зелёный; `go test ./...` в модуле control-plane зелёный (unit + contract).
2. Список нод динамический (из БД), нигде не зашит.
3. Нода → blocked ⇒ асинхронный пересбор наборов затронутых юзеров + инвалидация кеша.
4. Персональная изоляция: выдача юзера содержит только его секреты.
5. FieldSignal-агрегат от telemetry триггерит degraded/blocked.
6. sub_token хранится только хешем. Ни карт, ни платёжных данных.

## Слои (clean architecture)
- `internal/domain` — модели, порты (интерфейсы), доменные ошибки. Зависит только от `contracts`.
- `internal/usecase` — бизнес-логика (nodes/users/subscriptions/bundle/signals). Зависит от `domain`.
- `internal/adapters/postgres` — репозитории (pgx).
- `internal/adapters/httpapi` — HTTP по OpenAPI + аддитивные эндпоинты, auth-middleware.
- `internal/adapters/rebuild` — in-mem очередь пересбора конфигов.
- `internal/config`, `internal/migrate`, `internal/secret` — инфраструктура.
- `cmd/control-plane/main.go` — сборка зависимостей.

## Данные
users, subscriptions (token_hash), nodes, transports (jsonb params),
node_rotation_history, user_secret_rotations, subscription_sets (кеш+источник для Агента C),
node_signal_aggregates. Раннер миграций с advisory-lock (без race на старте).

## Эндпоинты
Frozen OpenAPI: nodes CRUD, users CRUD + rotate-secrets, subscriptions create/get, healthz.
Аддитивно (backward-compatible новые пути): POST /v1/signals/aggregate,
GET /v1/users/{id}/subscription-set, POST /v1/nodes/{id}/rotate.

## AuthN/Z
Bearer service-token → роль (admin/orchestrator/telemetry/subscription/billing).
RBAC на операцию. Токены из env, не в коде.

## Антиблок-инвариант
Blocked-нода (из FieldSignal или PATCH) ⇒ очередь пересбора ⇒ у юзеров новый набор
активных нод без ручных действий. Секреты персональные — блок одного не палит других.
