# ADR-003 — Клиенты: внешние (Happ / sing-box) через subscription

- **Статус:** принято
- **Дата:** 2026-07-07
- **Контекст:** `architecture.md` → «Клиенты», «Децентрализованная доставка конфигов»

## Контекст

Можно писать свои приложения на всех платформах (iOS Network Extension, Android
VpnService, Win/macOS) либо использовать готовые sing-box-совместимые клиенты
(Happ и др.), отдавая им конфиг по subscription-ссылке.

## Решение

**Свои приложения не пишем.** Берём готовые клиенты (Happ и sing-box-совместимые)
и интегрируемся через **subscription URL**. Сервис отвечает за выдачу и доставку
конфигов, клиент — за морфинг/переключение (логика в самом sing-box).

## Последствия

- **+** Резко меньше кода и платформенной возни; фокус на бэкенде и флоте.
- **+** Формат выдачи должен быть совместим с этими клиентами → контракт даёт три
  представления одного набора: base64-список URI, sing-box JSON, Clash-Meta YAML.
- **−** Ограничены возможностями внешних клиентов; кастомный UX-морфинг сверх
  sing-box недоступен без форка.
- Доставка подписки — мультиканальная ([[ADR-001]]): HTTPS/DoH/Telegram/GitHub
  raw/DNS TXT, чтобы блок сайта не рвал выдачу.
