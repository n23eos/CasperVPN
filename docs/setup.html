Shared flow

From invitation to connection

These steps are the same on phone and desktop.

  1. Install Happ

    CasperVPN uses Happ instead of a separate custom app. Choose your platform on the official Happ website and install it from the source linked there.

    • Do not install an app or package forwarded by an unknown account.
    • The pilot will check the current Happ version with VLESS REALITY and Hysteria2.

  2. Receive your personal link

    Open the approved bot in a private chat. After it confirms that access is active, tap «Подключиться». The legacy /get command does the same. The reply contains your persistent subscription URL and a Happ import link.

    Treat the subscription URL like a password. Do not post it, forward it or include it in screenshots.

  3. Import the subscription

    Open the Happ import link in the bot's reply. If direct import is unavailable on the device, copy the HTTPS subscription URL and add it in Happ as a link, URL or subscription.

    • Paste the complete URL without spaces.
    • Save or update the profile after import.
    • During the pilot, verify that Happ shows the personal VLESS REALITY and Hysteria2 entries.

  4. Enable and verify

    Select an imported entry, turn the connection on and accept the operating system's VPN permission. Open a normal website, then compare your public IP before and after connecting using a service you trust.

    • If one transport fails, try the other entry.
    • Confirm that DNS and ordinary browsing work.
    • If neither works, record the device, app version, network and error text for support. Do not include the subscription URL.

Device-specific details

Labels differ slightly between client versions. Look for actions named Add, Import, Subscription, URL or Clipboard.

iOS and iPadOS

Import, then allow the VPN configuration

  • Open the iOS option on the official Happ website and follow its current store link.
  • Return to the private bot and tap «Подключиться», then open the Happ import link or copy the subscription URL.
  • In the app, add a subscription from the clipboard or URL and save it.
  • When iOS asks to add a VPN configuration, review the app name and approve it with the device passcode.
Android

Add the subscription and approve the VPN prompt

  • Open the Android option on the official Happ website and follow its current store or official package link.
  • Tap «Подключиться» in the bot. Open the Happ import link or copy the subscription URL and import it from the clipboard.
  • Save the profile, select an entry and turn it on.
  • Approve Android's connection request after confirming it names the app you installed.
Windows, macOS and Linux

Install from the publisher and import by URL

  • Choose Windows, macOS or Linux on the official Happ website and download the current build linked there.
  • Open Add subscription or Import from URL and paste the complete link returned by «Подключиться».
  • Save, refresh the subscription if the app asks, then select a VLESS REALITY or Hysteria2 entry.
  • Allow only the operating system permissions needed to create the VPN or proxy connection.

If something does not work

Start with the symptom. Most setup problems can be separated from service access without exposing the private link.

The bot does not return a link

Make sure you are in a private chat with the approved bot and that payment or pilot activation is confirmed. Tap «Подключиться» again, or use /get. If access is pending, wait for the status to change or contact the pilot operator.

The app says the link is invalid

Open the Happ import link again or copy the full subscription URL without punctuation or spaces around it. Do not paste the private link into a public validator.

The profile imports but does not connect

Check that ordinary internet works without the VPN, try both imported transports and restart the app once. Send support the device model, OS, app version, network type and exact error. Remove the subscription URL from any screenshot or log excerpt.

The link worked before and now fails

Tap «Моя подписка» to check expiry and access state, then tap «Подключиться» to receive the same subscription again. An expired, revoked or suspended account cannot import usable access.

Waiting for a pilot invitation?

You can install Happ from its official website. The real bot address, current plans and support contact should come from the same trusted invitation.
