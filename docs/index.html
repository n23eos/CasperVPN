The parts a pilot user needs

The pilot flow is prepared: the bot shows access status, delivers a personal link and can return the same subscription again when needed.

01

Personal access

The private bot binds access to one account. After activation, the Connect button returns that user's persistent subscription link.

02

External app

CasperVPN does not require a custom app. The bot provides a direct Happ import link and the personal subscription URL.

03

Access lifecycle

The bot shows whether access is active and when it expires. Requesting the link again does not replace the current subscription.

The pilot connection path

Once an operator invites you, the actual flow is short and keeps server credentials out of the setup page.

01

Use the approved bot

Open the bot address supplied directly by the pilot operator and complete the available account or plan steps.

02

Request your link

After access is active, tap «Подключиться». The legacy /get command also works. Keep the returned link private.

03

Import and verify

Open the Happ import link from the bot, enable the profile and check the connection. You can also paste the subscription URL into Happ.

Good to know

Short answers for the questions that matter before the pilot opens.

Can I buy access now?

No public sale is announced on this site. Pilot participants receive the real bot address, available plans and support contact from the operator.

Does CasperVPN guarantee access on every network?

No. Local tests do not prove behavior under a specific carrier or filtering system. That evidence comes from the closed pilot on real infrastructure.

Which app should I install?

Use Happ from its official source. The pilot will confirm how the current app version handles both connection options on your device.

Prepare your device before the invitation

Choose iPhone, Android or desktop and see the complete install, import and verification flow without entering any private configuration on this site.
