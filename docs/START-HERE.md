## ✅ Квест 1 — запустить проект локально

**1. Перейди в папку проекта** (подставь свой путь, если другой):
```bash
cd ~/code_projects/CasperVPN
```

**2. Подними весь стек** (postgres + 6 сервисов):
```bash
make up
```
- ✅ Идёт сборка, потом строки вида `Started` / `Running`. Первый раз — 2–5 минут (качает образы).
- ❌ Долго висит / «connection refused» на образах → это флаки-загрузка. Просто повтори `make up`. Если совсем застряло — `colima restart`, потом снова `make up`.

**3. Проверь, что сервисы живые** (каждый должен ответить `ok`/`200`):
```bash
for p in 8081 8082 8083 8084 8085 8086; do
  printf "port %s -> " "$p"; curl -s -o /dev/null -w "%{http_code}\n" http://localhost:$p/healthz
done
```
- ✅ Видишь `200` (или `ok`) напротив портов → **все 6 сервисов работают.**
- ❌ Часть портов `000`/пусто → подожди 20 секунд (стартуют) и повтори команду.

**Что на каких портах** (просто чтобы знать):
| Порт | Сервис | Что делает |
|------|--------|-----------|
| 8081 | control-plane | мозг: ноды, юзеры, ключи |
| 8082 | subscription | выдаёт клиенту ссылку-подписку |
| 8083 | delivery | доставка ссылки по каналам |
| 8084 | billing | оплата/подписки |
| 8085 | telemetry | сбор сигналов «где заблокировали» |
| 8086 | orchestrator | поднимает/меняет серверы |

- [ ] **Квест 1 пройден** — стек живой 🎉

> Остановить всё, когда наигрался: `make down`

## ✅ Квест 4 — настоящий VPN-туннель локально (опционально)

Это поднимает реальную ноду sing-box и гонит трафик через REALITY-туннель **на твоей
машине** (без сервера в облаке). Нужна одна вещь от тебя: **домен-мимикрия** — любой
крупный сайт на TLS 1.3 (его хендшейк «крадёт» REALITY). Домен НЕ хардкодится — ты
даёшь его сам.

```bash
REALITY_DEST=<домен>:443 REALITY_SERVER_NAME=<домен> make e2e-real-node
```
Пример: подставь вместо `<домен>` реальный хост (см. `docs/mimicry-domains.md` — там
кандидаты, но выбор за тобой).

- ✅ В конце `PASS` + строки, что туннель отдал HTTP-ответ, а приватный ключ никуда не утёк.
- ⏭️ Если пропустил (env не задан) → тест напишет `SKIP` и выйдет — это норм.
- ❌ `FAIL: … TLS 1.3` → домен не говорит по TLS 1.3, возьми другой.

- [ ] **Квест 4 пройден** (или осознанно пропущен) 🎉

## 🆘 Если что-то сломалось (частое)

| Симптом | Что нажать |
|---------|-----------|
| Docker «cannot connect» | `colima start` (или запусти Docker Desktop) |
| `make up` висит на загрузке образа | повтори `make up`; не помогло → `colima restart` |
| порт занят / `port busy` | `make down`, подождать 5 сек, повторить |
| туннель/тесты странно виснут | `colima restart`, потом заново |
| «нет места» / диск | `docker system prune -f` (удалит мусор образов) |
| хочу всё остановить | `make down` |
| хочу начисто | `make down && docker system prune -f`, потом `make up` |

> Мак + Colima: наружу монтируется только домашняя папка (`$HOME`). Если проект лежит
> вне `$HOME` — тесты с docker-mount могут молча не видеть файлы. Держи проект под `~`.
