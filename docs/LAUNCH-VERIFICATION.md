## Зафиксированные исправления

- Начисление оплаты хранит durable outbox и абсолютное состояние с revision.
  Проверены crash/retry, изменение порядка delivery, смена тарифа, grace,
  пул PostgreSQL размером 1/2 и ограничение времени HTTP-запроса.
- Subscription сверяется с CP до cache hit, учитывает ban/expiry/grace,
  не возвращает DIRECT-only при пустом флоте и не раскрывает общие секреты нод.
- Постоянная ссылка хранится в CP как hash и защищённый ciphertext;
  частичный status PATCH сохраняет Telegram identity.
- VLESS и Hysteria2 используют персональные секреты и access snapshot.
  Просроченный или повреждённый lease останавливает доступ.
- Lifecycle использует manifest/workspace identity, а старая нода уходит
  в draining после готовности замены.
- Legacy ручная выдача прав доступна admin. Публичные полевые отчёты
  не запускают автоматику. Rate limit различает клиентов доверенного proxy.
- Production требует БД и постоянные независимые ключи. Публикация проверяет
  публичный DNS/TLS и subscription до старта Telegram poller.
- Docker-сборка ограничивает память компилятора и проходит в локальной
  Docker VM примерно с 2 GiB RAM. Runtime-образы работают без root.

## Версии и воспроизведение

Go 1.27.1, PostgreSQL 16, sing-box 1.14.2, golangci-lint 2.14.0,
govulncheck 1.8.0, OpenSpec 1.13.0. Системный Go 1.20 не подходит.
После выбора правильных инструментов в PATH:

```sh
make release-check
```

Дополнительная проверка синтаксиса Ansible требует окружение и collections
из `infra/ansible/requirements.yml`:

```sh
make infra-syntax
```

Основной локальный лог проверки:
`~/.codex/tmp/caspervpn-launch/release-check-current-core.log`.
Логи сборок находятся рядом в `docker-*.log`. Они не являются частью
репозитория. CI workflows обновлены, но новый удалённый прогон GitHub Actions
в рамках этой подготовки не запускался.

## Что ещё требует реального запуска

- Подставить домен/DNS, Telegram bot token, BTCPay store/key/webhook,
  утверждённые тарифы и учётные данные инфраструктуры.
- На Linux/VPS проверить создание entry/exit, systemd timer, watchdog,
  SSH/Ansible, ротацию, сетевые ACL и восстановление после потери CP.
  Полный Molecule и создание VM здесь не выполнялись.
- Проверить один реальный минимальный платёж и повтор webhook,
  импорт в конкретный клиент и DNS/egress из целевых сетей.
- Измерить нагрузку, разрывы соединений при обновлении конфигурации и
  поведение при DPI. Проверка JSON не доказывает работу приложения на телефоне.
- Назначить production backup schedule, retention, внешний зашифрованный
  backup и мониторинг. Локальная репетиция не подтверждает эти настройки.

Traffic/speed/device quotas пока не принуждаются на data plane. On-chain
библиотеки не подключены к поддерживаемому запуску. Смена главного ключа
шифрования ссылок требует отдельной процедуры; нельзя просто заменить env.
Старые незавершённые settlements требуют сверки перед обновлением уже
работавшей установки. Эти границы отражены в [инструкции запуска](LAUNCH.md).

Подготовка не выполняла покупку ресурсов, настоящие платежи, отправку
сообщений реальным пользователям или production deploy. Итоговые изменения
оставлены в рабочем дереве для просмотра; отдельные Git-сохранения владельца
не заменяют приёмку именно этого итогового дерева.
