# Кандидаты доменов мимикрии (REALITY)

> **Это НЕ хардкод.** Ни один домен отсюда не зашит в код/шаблоны. Домен мимикрии
> выбирается **на каждый деплой** и подаётся переменной
> (`transports.vless_reality.server_names` / `handshake_server`). Здесь — только
> критерии выбора и стартовый список кандидатов для оператора/оркестратора.

## Как REALITY использует домен

REALITY «крадёт» TLS-хендшейк реального крупного сайта: нода не имеет своего
сертификата и своего TLS-фингерпринта. Активный пробинг, постучавшись на нашу
ноду, видит **настоящий** чужой сайт (`handshake_server`), а трафик выглядит как
обычный HTTPS к нему, а не как «энтропийный шум». Поэтому домен-цель должен быть
таким, который цензор **не станет** ломать.

## Критерии выбора (обязательные)

1. **TLS 1.3 + X25519 + HTTP/2.** Обязательно для REALITY. Проверять до деплоя.
2. **Крупный, «дорогой для блокировки».** Массовый CDN / сервис, чья блокировка
   бьёт по легальному трафику и потому маловероятна (collateral-freedom).
3. **Не связан с VPN/прокси** и не в чёрных списках.
4. **Географически правдоподобен** для целевого рынка (не выбивается из профиля
   обычного пользователя).
5. **Стабилен**: не редиректит, не отдаёт разные серты, не за нашим же облаком.
6. **Разнообразие пула.** Разным нодам — разные домены; блок одного ≠ монокультура.

## Категории кандидатов (примеры, выбирать и проверять per-deploy)

| Категория | Почему подходит |
|-----------|-----------------|
| Крупные CDN fronts | огромный collateral, TLS1.3, повсеместны |
| Мейнстрим SaaS / облачные консоли | «дорого» ломать, деловой трафик |
| Госзначимые/платёжные сервисы целевого рынка | цензор не станет рвать |
| Популярные медиа/стриминг edge | правдоподобный профиль, H2/H3 |

Конкретные домены-кандидаты держите в **конфиге оркестратора / секрет-менеджере**
(список, из которого выбирается per-node), а не в этом файле и не в коде. Пример
формы записи (значения — плейсхолдеры, замените под свой рынок):

```yaml
# orchestrator config (НЕ в git с реальными значениями)
mimicry_pool:
  - server_names: ["<major-cdn-host>"]
    handshake_server: "<major-cdn-host>"
  - server_names: ["<mainstream-saas-host>"]
    handshake_server: "<mainstream-saas-host>"
```

## Проверка домена перед использованием

```bash
# TLS1.3 + X25519 + HTTP/2 ALPN?
openssl s_client -connect <host>:443 -servername <host> -tls1_3 -alpn h2 </dev/null 2>/dev/null \
  | grep -E 'Protocol|ALPN|Cipher'
# sing-box умеет проверить пригодность dest под REALITY:
sing-box tools reality-dest --server <host>:443   # (если доступно в вашей сборке)
```

Ротация домена — часть ротации ноды (`make node-rotate`): при подозрении на
детект меняем и ключи, и, при необходимости, домен мимикрии из пула.
