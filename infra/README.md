# infra — инфраструктура флота (плейсхолдер)

Владелец: команда infra (тесно с `services/orchestrator`). Пока пусто.

- `terraform/` — provision нод по нескольким облакам (мультиоблако — антихрупкость).
- `ansible/` — конфигурация ноды: установка/настройка **sing-box** (ADR-002),
  ключи, ротация.

Принципы (см. `architecture.md`):
- Нода поднимается за минуты; одноразовые эфемерные точки входа.
- Разделение entry/exit; быстрая ротация IP.
- **Ноль хардкода** доменов мимикрии и IP — только переменные/секреты.

Оркестрацией жизненного цикла (provision/ротация/автозамена, детект блокировок)
рулит `services/orchestrator` через контракт `Node`/`HealthEvent`.
